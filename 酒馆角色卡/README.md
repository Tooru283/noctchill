# noctchill 酒馆角色卡 v2.0

基于本仓库的剧情分析档案 + 官方站资料生成。四人各一张，共用一本世界书和一套预设。

## 导入顺序（顺序不能乱）

**1. 预设** —— API 连接页导入 `noctchill_preset.json`，并**在下拉里选中它**
> ⚠ 不要用高武纪元那套预设跑这些卡。那套写着「正文之后输出简讯→选项→状态三块」，和这里的「择／场」直接冲突，结果是两边都不出。

**2. 世界书** —— 导入 `noctchill_lorebook.json`

**3. 角色卡** —— 导入四张 `card_*.json`
> ⚠ 酒馆导入同名卡是**新建不是覆盖**。先把旧的 noctchill 卡全删干净。
> 分辨方法：进卡后看开场白翻页，**`1/4` 是 v2，`1/3` 是旧版**。

**4. 每张卡进去后，在角色页把世界书绑上** —— 不绑的话另外三人出场会串味，格式也会崩。

**5. 正则** —— 扩展 → Regex，**按编号顺序**逐个导入（旧的四条先删掉）：

| 文件 | 作用 |
|---|---|
| `regex_nc_01_scene` | 场·外框（CSS 内联在这条里） |
| `regex_nc_02_scene_meta` | 时/所/人 → 行内并排 |
| `regex_nc_03_scene_air` | 空气 → 斜体行 |
| `regex_nc_04_scene_unsaid` | 未言 → 左边框行 |
| `regex_nc_05_choice` | 择·外框 |
| `regex_nc_06_choice_rows` | 择·条目（行动 ／ 反应） |
| `regex_nc_07_choice_plain` | 择·无反应时的兜底 |
| `regex_nc_08_trim` | 剥离历史区块，省 token |
| `regex_nc_09_dialogue` | 日文提亮、中译压暗 |

**6. 开一局新的。** 旧聊天记录里满屏是旧格式，模型会照着最近的样式续写，配置换新也没用。

## 输出结构

模型实际写出来的是这样（**冒号格式，不是方括号**）：

```
<择>
1. 坐到窗台上去 ／ 她会往旁边挪半个位置，不说话
2. 说一个数字 ／ 她会看你很久，然后决定信不信
3. 什么都不说，站在原地 ／ 她也不会催。她比你能等
</择>

<场>
时：三月的夜里 · 19:52
所：283プロ 事务所 · 靠国道的那扇窗
人：透
空气：她把一个不需要答案的问题递过来了。窗一直开着，没人去关。
未言：她想知道的不是有几个。是你会不会陪她数完。
</场>
```

渲染后：`时 / 所 / 人` 并排一行灰色小字，`空气` 是下面的斜体，`未言` 带一条暗红左边框。

> **为什么是冒号不是方括号**：v2.0 用的 `[字段|值]` 模型总写崩，而且它会自己漂向冒号格式——那说明冒号是它想写的。顺着改比硬掰划算。
> 现在的正则对格式很宽容：项目符号、`1)` `1.` `1、`、全角半角冒号、甚至旧的方括号写法，都能吃。字段名写成「时间/地点/在场」也认。

### 两个自定义机制

**「未言」** —— 正文里**禁止**写内心独白，情绪只能靠动作和停顿走。她想说没说的那句统一放这一栏。规则不是「不许写心理」而是「心理写在指定位置」，模型有出口就不会往正文漏。
四人各有各的用法：透是 `……` 里省掉的｜円香是敬语底下压着的｜小糸是咽回去的｜**雛菜永远写「（无）」**——她说的话字面意思就是全部意思，这一栏在她这里是反向证明。

**「择」** —— 三条不同方向（接住／不接／反问），第二栏预测她的反应，要贴各自的行为规则表。**沉默永远是合法选项**，对这四个人来说不说话经常比说话有效。选项只是提示，不选也不会卡住剧情。

## 四条最容易写崩的语癖

| 角色 | 一人称 | 关键 |
|---|---|---|
| 浅倉透 | 私 | `……` 极多，句子极短，不填补沉默。「お兄ちゃん」是重武器，禁止连用 |
| 樋口円香 | 私 | 敬语是墙。**掉成タメ口的瞬间＝墙裂了**，这是她最重要的表达手段 |
| 福丸小糸 | わたし | 「ぴゃっ」→ 结巴。但**进入专业领域会换一个人**：语速平稳、逻辑清楚 |
| 市川雛菜 | **雛菜** | 自称本名，**绝不用「私」**。这是最容易崩的一条 |

## 三条硬禁令（写进卡里了）

- 雛菜不许安排"其实内心脆弱"的转折，也不许写成没脑子的废萌
- 円香不许滑向傲娇模板，不许轻易服软
- 小糸不许只写成怯懦吉祥物——核心是韧性，该站出来时会站出来，站出来之后才发抖

## 分层（改东西时看这里）

| 层 | 内容 | 变动频率 |
|---|---|---|
| 预设 | 叙事契约、文风、禁套话 | 通用，基本不动 |
| **世界书 ★N3** | 「择」「场」的完整模板与规范 | **唯一真源**，改格式只动这一条 |
