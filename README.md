## 这是什么

对《偶像大师 闪耀色彩》中偶像组合 **noctchill** 四位成员的系统性剧情分析。

不是剧情汇总，也不是攻略。这里做的是**文学批评**——把每张卡面当成文本来读，追踪意象、结构与精神弧光。

| 成员 | 目录 | 核心主题 |
|---|---|---|
| 浅仓透 Asakura Tooru | [`tooru/`](tooru/) | 透明与重量——从虚无中被发现的灵魂 |
| 樋口圆香 Higuchi Madoka | [`mdk/`](mdk/) | 长满荆棘的大地——寻找「真物」与害怕希望的撕扯 |
| 福丸小糸 Fukumaru Koito | [`kit/`](kit/) | 凡人的逆袭与和解——把脚放到地上 |
| 市川雏菜 Ichikawa Hinana | [`hnn/`](hnn/) | 快乐的存在主义者——拒绝被定义的幸福论 |

## 怎么读

- **想了解某个角色** → 从她目录下的 `主线剧情.md` 开始，那是骨架
- **想看单张卡的拆解** → 目录下按卡名命名的文件，每篇独立成文
- **想知道还缺什么** → 每个目录里的 `_剧情清单.md`，完成度勾选表
- **想拿去玩** → [`酒馆角色卡/`](酒馆角色卡/)，四张可直接导入 SillyTavern 的对话卡

目前覆盖 **enza 版《闪耀色彩》（シャニマス）**：主线四篇章 + P-SSR 卡面剧情。

## 四个人

### 浅仓透 · [`tooru/`](tooru/)

> 「啊，那个人，发现我了。」

她曾经是透明的。不是隐形，是从内部开始变得稀薄——不相信自己的存在会留下痕迹，也不相信有人会真的看见她。

主线以**磁带与卡带**为核心意象，谈时间、记忆与终结。从被制作人「发现」的那一刻起，她开始了漫长的学习：如何贪恋，如何失去，如何把灵魂刻进这个世界。

### 樋口圆香 · [`mdk/`](mdk/)

> 「那就请和我一起下地狱吧。」

毒舌是铠甲，敌意是试探，对「真物」的执念源自对赝品的极度恐惧。她八成的恶意都朝向自己。

她知道世界虚伪，却被迫承受期待；因为太想相信，所以先选择不信。她的故事是一个问题：**当一个精神洁癖者爱上了满是污垢的世界，她该怎么办。**

### 福丸小糸 · [`kit/`](kit/)

> 「見つけてくれて、ありがとうございます」

四个人里唯一一个没有被找到的。街头搭讪那次制作人叫住了透、圆香和雏菜，唯独漏了她。于是她自己撒着谎冲进事务所——比起当偶像，她更怕被那三个人丢下。

一部凡人的逆袭与和解史：用谎言堆起纸城堡（W.I.N.G.）→ 被「运气真好」四个字钉在原地（G.R.A.D.）→ 终于把脚放到地上（Landing Point）→ 可以从容地把功劳让出去（【セピア色の孤独】）。

她和母亲那条线不是「终于互相理解」，是「想过头的母亲」与「只想被认可的女儿」之间那个细小而巨大的错位——彼此都在用力，彼此都没接住。

### 市川雏菜 · [`hnn/`](hnn/)

> 「雛菜は、雛菜がしあわせならそれでいいの～」

彻底的快乐主义者，但不是幼稚的那种——她的幸福论经过缜密建构。拒绝「为了未来就得现在吃苦」的逻辑，拒绝被他人期待定义价值，拒绝任何形式的「结局」。

她只要永远的 **Happy-ING**。

## 分析框架

每篇主线分析采用七层结构（详见 [`prompt.md`](prompt.md)）：

情感弧光 → 四大篇章映射 → 主线戏剧结构 → 补完卡面 → 主题解析 → 细节拾遗 → 全卡面总览

### 写作原则

- **意象锚定**　所有论点必须绑定剧情中实际出现的场景、台词或物件，禁止空洞议论
- **看得见的隐喻**　文学解读必须是「可以指认」的，而非强行附会
- **不复制原文**　游戏剧本版权归万代南梦宫。本库只做情节转述与解读，「核心台词」小节仅在有确切出处时收录，逐条标注
- **拒绝盖棺论定**　角色永远比任何解读更复杂

## 酒馆角色卡

[`酒馆角色卡/`](酒馆角色卡/) 里是四张可直接导入 SillyTavern 的单人对话卡，时间线设在 Landing Point 之后，玩家扮演制作人。中文叙述 + 日文台词带中译。

设计上有两个不太常见的做法：

- **行为规则表**　性格不用散文描述，改成「触发 → 反应」的对照表。散文出通用输出，触发表出具体输出
- **「未言」栏**　正文里禁止写内心独白，情绪只能靠动作和停顿走；她想说没说的那句统一收在场景块的这一栏。规则不是「不许写心理」而是「心理写在指定位置」
  - 雏菜是例外：她的「未言」恒为「（无）」——她说的话字面意思就是全部意思

导入步骤与注意事项见该目录下的 [README](酒馆角色卡/README.md)。
